# ubereats-ui-redesign
This project is a UI/UX redesign of a food delivery app. It focuses on improving usability, modern design, and providing a better user experience with a simple and intuitive interface.
# Uber Eats UI/UX Redesign

## Project Overview
This project redesigns the onboarding and authentication flow of the Uber Eats mobile application to improve:
- Visual hierarchy
- Accessibility
- User flow
- UI consistency

## Screens Included
- Splash Screen
- Onboarding Screen
- Login Screen
- Register Screen
- Home Screen
